## 这是什么

一套**可直接上会、可交教务**的高职专业课程改革完整材料：从企业岗位调研到六表建模、人才培养方案、四门学习领域课程标准、6×4 分层教案，再到**每个学习情境的学生互动学习模块与教师授课包**，全部按院校既有文件体例交付 Word/PDF。

**一句话结论**：内部逻辑与体例交付可用；**外部证据薄弱**——本专业一手访谈为 0，11 项任务全部依赖 460310（工业互联网应用）的跨专业迁移证据。评审批次前必须补企业访谈。

## 怎么用

1. **看结论** → `00_材料包说明.md`
2. **查数字** → `99_审核报告_V1.0.md`，再跑 `_校验脚本/全链校验.py` 复算
3. **要交件** → 根目录 `*.docx` / `*.pdf`（院校版式，Word 可直接改）
4. **要上课** → `教学资源/教师授课包/`（教师）+ `教学资源/学生互动模块/`（学生，浏览器直接打开，离线可用）
5. **要答辩** → `00_体例核验与交付清单.md` 第六节（Word/PDF 转换与验收记录）

## 必须知道的边界

- **专业教学标准未发布**：本专业 2024-12 增设，教育部标准截至 2026-10 未发布。全链按降级路径处理，课程池对标为二手材料，**不得表述为"符合国家教学标准"**。
- **一手证据为 0**：11 项任务全部依赖跨专业迁移证据；等级分布有意偏离常规形态（L2 超上限 12.5pp，L4 归零），并给出了回补预案与触发条件。
- **教学资源覆盖 11 个学习情境**（专业核心 432h），不是全部 43 门课程——其余 32 门尚未编课标，因此没有互动资源。
- **AIGC 标识**：全部文件未预置 `ContentProducer`／`ProduceID`，由院校按《人工智能生成合成内容标识办法》填写。
