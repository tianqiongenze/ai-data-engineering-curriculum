05引导文六问

学生自己找答案，教师只回答"往哪找"，不直接给判定结论。

  1. 资讯：这批要交什么？三项基线值是多少、各由指标定义里哪一条说了算？四类问题在你这批数据里各长什么样、各配哪个处置动作？
  2. 计划：检测项列几项？判定阈值定多少？四类问题各自的处置动作是什么？复检口径是什么？2 人怎么分工（执行／复核）？"变更怎么记"那一栏你写了几条？
  3. 决策：异常值为什么只标记不删？原始副本哈希怎么留、留哪、谁登记？被质疑"删了指标更好看"时，你拿哪条约束顶回去？
  4. 实施：备份做了吗、哈希是多少？四类检测跑完分布是什么样？指标算出来和基线差多少？刚才那条变更登记了"谁改／改哪／依据"没有？
  5. 检查：你怎么证明指标算对了？双算偏差是多少、超没超 1%？日志抽查 20% 抽到你哪条、三要素全不全？
  6. 评价：哪类问题最费时间、为什么？这次踩的坑能不能写成一条规则修改建议——"下次该改哪条规则"写进报告了没有？

08典型错误案例卡（3 张）

ERR-LF2-Q1-001：删除异常记录而非标记（红线②，本情境头号错）

现象：一组为"让异常占比达标"，把 37 条超量程行（vib_peak＝99.99 等）直接删除，指标好看但触发红线②，被当众公布。

错误做法：删了就当干净了，没恢复、没报告，还问"指标不是达标了吗"。

真实原因：把"达标"理解成"把不好看的数去掉"；没读懂约束"异常值只可标记不可删"，也不知道交付走"可用集口径"。

排查路径：① 比对原文件与清洗集行数 → ② 查变更日志有无删除记录 → ③ 对照红线②与处置规则表。

后果：本情境 0 分＋恢复数据；且异常行被删后数据分布被篡改，模型学到错误关联——这正是 LF2-Q2"模型 mAP 下降 8pp"的源头之一。

预防措施：异常行一律"标记＋隔离＋登记"三动作；指标看可用集口径，不看删完的口径；计划表强制栏"异常值怎么处置"由教师课前核。

关联原子：LF2-Q1-A08（按处置规则清洗并保留原始副本与变更日志）

ERR-LF2-Q1-002：指标口径不一致，双算偏差 3.6%

现象：自算完整率 99.1%，工具算 95.5%，双算偏差 3.6%，远超 ≤1% 要求，整批判回。

错误做法：以自己算的为准，说"工具肯定有问题"，不复查口径。

真实原因：自算把空字符串当有值、把哨兵值 -999 当正常读数；工具按指标定义把两者都计为缺失。口径不一致，不是算术问题。

排查路径：① 对照指标定义逐条核边界 → ② 抽 20 行手工复算 → ③ 定位口径分歧字段（空串／哨兵值／单位混用）。

预防措施：算指标前先读指标定义；边界值单列清单写进计划表；双算由同伴独立完成，不当场对答案。

关联原子：LF2-Q1-A28（按指标定义算完整率／重复率／异常占比，与工具结果偏差 ≤1%）

ERR-LF2-Q1-003：未备份原始副本即清洗，覆盖原文件（红线①）

现象：为省 10 分钟跳过备份直接清洗，脚本回写覆盖原文件，全批无法回溯。

错误做法：悄悄重跑一遍当没发生；或把覆盖后的文件当清洗结果继续交。

真实原因：把备份当"可选步骤"；赶 48h 交付期；不知道哈希是"未被覆盖"的可检查凭证。

后果：触发红线①"本情境 0 分＋重做"；原文件无法恢复，整批须重新入库。

预防措施：备份＋哈希是清洗第一个动作，写进工位看板；没见哈希不动手；脚本回写一律先dry-run 到沙箱。

关联原子：LF2-Q1-A08（先备份后变更）

09安全提示卡（D 类红线·3 条）

红线即一票否决，四层要求完全相同（课标原文）
序红线条目（可检查动作）后果检查人/方式
1未备份原始副本即清洗（覆盖原文件）本情境 0 分＋重做教师查只读区备份与哈希登记
2删除异常记录而非标记本情境 0 分＋恢复数据行数比对＋变更日志＋双算
3变更无日志该条变更判无效并整批重洗日志抽查 20%，查三要素

课前 3 分钟由当班安全员复述红线 1 条；违规按"停线—记录—复盘—复训"四步处理。AI 三层梯度（⑦.3）：🔴 禁用 AI 直接连接数据库执行清洗或写回；🟡 LLM 出清洗脚本草案、人逐行复核并小样本试跑，每份产出附 T11；🟢 SQL 语法查询、术语与报错解释全员可用，但不得用于交付物的事实性内容与结论。

10教师备课备注

高频错判 Top3（按发生概率排序）
  1. 把异常行删了"让指标好看"：红线②，一票否决。纠法——计划表强制栏"异常值怎么处置"课前逐组核；开洗前用 3 行样例现场问"这行删不删"。
  2. 缺失行不补采直接删：完整率必崩。纠法——强调"补采不回须登记原因"，删是兜底不是首选；检测出缺失先问"采集端还能回补吗"。
  3. 格式问题当异常处理：该泛化不泛化，双算偏差超标。纠法——速查表"长相"列带学生过一遍：时间戳／单位／编号不统一＝格式，不是异常。
答疑口径：只指条文，不代判

学生追问"标准答案"时，只答"去查哪一条第几款"：指标定义第几条、处置规则表 R 几、约束与红线第几条。不代判、不代写脚本；教师巡视只纠红线（覆盖原文件、无日志改动）。
